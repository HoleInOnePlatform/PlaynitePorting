# HoleInOne 아이콘

내장 ImageGen으로 생성한 민트색 H + 원형 포털 아이콘. 어두운 원형 바탕으로 밝은 작업 표시줄과 어두운 작업 표시줄 모두에서 형태가 유지됨. 원 밖은 투명함.

- `holeinone.png`: 생성 원본(1254 × 1254, 알파 포함)
- `holeinone.ico`: Windows 아이콘(16, 20, 24, 32, 40, 48, 64, 128, 256px)
- `preview.png`: 256px 미리보기
- `generation-prompt.txt`: 사용한 생성 도구 및 전체 프롬프트

원본에서 배포용 파일 재생성:

```powershell
./build/Apply-HoleInOneBranding.ps1
```

원본 디자인과 투명도를 유지한 크기 변환·ICO 포장만 수행함. 기본 테마의 기존 `applogo*` 파일명은 리소스 참조 호환성을 위해 유지함. 실행 파일·트레이·메뉴·기본 게임 이미지·시작 화면·브라우저 보조 프로세스·확장 파일 아이콘에 동일한 디자인을 적용함. 트레이의 흰색/검정색 설정도 새 아이콘을 사용함.

적용 후 `Build-HoleInOne.ps1`로 다시 빌드해야 실행 파일에 아이콘이 포함됨. 원본 Playnite 설치기와 외부 스토어 로고는 변경하지 않음.
