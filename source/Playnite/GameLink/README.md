# GameLink handoff contract

The default session address provider starts the bundled GameLift Streams web client on a per-view loopback HTTP port. See [WebClient/PLAYNITE_SETUP.md](WebClient/PLAYNITE_SETUP.md) for required AWS and SDK inputs. An injected `IInstantPlayAddressProvider` may still supply an HTTPS or loopback HTTP URL. The default local handoff returns failure because save restore and continuation confirmation are external responsibilities. It never closes the cloud view on failure.

The streaming page forwards authenticated GameLink events with `CefSharp.PostMessage(JSON.stringify(event))`. Only main-frame messages from the session URL's origin are accepted. Messages are limited to 8192 characters and version 1. `eventId`, `sessionId`, and `handoffId` are UUIDs; `sequence` increases per session. The `gameId` equals the Playnite game's provider `GameId` (or Playnite `Id` if absent). Required fields are `version`, `type`, `eventId`, `sessionId`, `gameId`, `sequence`, and `occurredAtUtc`. `handoff.ready` also requires `payload.handoffId` and opaque `payload.artifactId`. The producer promises that local installation, version, DLC, mod compatibility, artifact transfer and restore feasibility have all been checked before sending ready. Playnite does not inspect the artifact. The local handoff callback must only return success after save restoration and local continuation are confirmed.

`handoff.point.reached` is observational. Only `handoff.ready` starts a switch. Failed or cancelled signals leave the cloud view open. The page must query the coordinator for the current session snapshot on every load/reconnect and replay it with a sequence greater than the last emitted sequence. A fresh page must not reset its sequence. The source of truth remains the GameLink coordinator, not this in-memory Playnite session.

The `rest_site_reached` data-channel signal uses a separate strict JSON contract. The web client forwards it through the same bridge, and the active instant-play view records it without passing it into `HandoffSession` or closing the stream. For legacy handoff development, `mock.html` remains available as a manual fixture, but it is no longer the default instant-play address.
